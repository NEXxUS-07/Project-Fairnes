  1. FASTAPI BACKEND  (port 8000)
================================================================================

Location:   /home/nexxus/Documents/Project Fairness/backend/
Venv:       backend/.venv/
DB:         SQLite → backend/app.db  (dev mode, auto-created on first start)
ML mode:    DUMMY (random predictions, placeholder images — no model files needed)

--- FIRST TIME SETUP (run once) ---

  cd "/home/nexxus/Documents/Project Fairness/backend"

  # Create virtual environment
  python3 -m venv .venv

  # Install dependencies
  .venv/bin/pip install fastapi "uvicorn[standard]" python-multipart \
      sqlalchemy aiosqlite pydantic pydantic-settings slowapi alembic pillow numpy

  # Create .env (already done — file exists at backend/.env)
  # Contents:
  #   DATABASE_URL=sqlite+aiosqlite:///./app.db
  #   ML_DUMMY_MODE=true
  #   DIFFUSION_DUMMY_MODE=true
  #   SECRET_KEY=local-dev-secret-key-change-in-production
  #   ALLOWED_ORIGINS=http://localhost:3000,http://localhost:5173

--- START BACKEND ---

  cd "/home/nexxus/Documents/Project Fairness/backend"
  ML_DUMMY_MODE=true DIFFUSION_DUMMY_MODE=true \
    .venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --log-level info

  # Background (saves log):
  ML_DUMMY_MODE=true DIFFUSION_DUMMY_MODE=true \
    nohup .venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --log-level info \
    > /tmp/backend.log 2>&1 &

  # With hot-reload (development):
  ML_DUMMY_MODE=true DIFFUSION_DUMMY_MODE=true \
    .venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --reload

--- STOP BACKEND ---

  pkill -f "uvicorn main:app"

  3. DATABASE  (PostgreSQL 18 — optional, SQLite used by default in dev)
================================================================================

PostgreSQL 18 is installed on this machine at:
  Cluster:    pg_lsclusters → Ver 18, Port 5432
  Data dir:   /var/lib/postgresql/18/main/
  Log:        /var/log/postgresql/postgresql-18-main.log

--- START POSTGRESQL (requires sudo) ---

  sudo systemctl start postgresql
  pg_isready -h localhost -p 5432   # confirm it's up

--- CREATE DATABASE ---

  sudo -u postgres psql -c "CREATE USER fairness WITH PASSWORD 'fairness_pass';"
  sudo -u postgres psql -c "CREATE DATABASE skinlesion_db OWNER fairness;"

--- SWITCH BACKEND TO POSTGRESQL ---

  # Edit backend/.env:
  DATABASE_URL=postgresql+asyncpg://fairness:fairness_pass@localhost:5432/skinlesion_db

  # Run migrations:
  cd "/home/nexxus/Documents/Project Fairness/backend"
  .venv/bin/alembic upgrade head

--- STOP POSTGRESQL ---

  sudo systemctl stop postgresql

================================================================================
  10. WHAT EACH SERVICE DOES
================================================================================

  FastAPI (port 8000)
    • POST /api/predict        — classify a skin lesion image (EfficientNet-B3)
    • POST /api/explain        — Grad-CAM + SHAP explanations
    • POST /api/generate       — synthetic image generation (DDPM)
    • GET  /api/history        — prediction history from SQLite
    • GET  /api/metrics/fairness — fairness metrics (DPD, EOD, per-class AUC)
    • GET  /api/dashboard/stats  — dashboard summary stats

  React Frontend (port 5173)
    • Dashboard    — stats overview, fairness scores, class distribution
    • Predict      — drag & drop image upload, confidence gauge, Grad-CAM overlay
    • History      — searchable table of past predictions
    • Metrics      — before/after fairness charts, confusion matrix heatmap
    • Generator    — synthetic image generation UI with class selector

  SQLite (backend/app.db)
    • Tables: predictions, synthetic_images, model_metrics,
              fairness_reports, generation_jobs
